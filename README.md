Entry for the [make.fun competition "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` writes one short original text to `/output/entry.txt`: a small open mystery, a door in a familiar house that was never noticed until tonight, left unanswered so the reader keeps asking. It runs on Node 22 with no dependencies and no network access, and its output is fully deterministic.
